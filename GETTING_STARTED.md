# Content Factory — starter UI

This is a dependency-free, responsive UI prototype for the Content Factory product direction. Open `index.html` in a browser. The content generation interaction is a local prototype and does not call an AI provider.

## Run locally
- Open `index.html` directly, or serve this folder with any static HTTP server.
- No API keys are needed for this UI-only prototype.

## Next integration steps
1. Pick the production stack and deploy target.
2. Add authentication and persistent project/draft storage.
3. Implement a server-side AI endpoint and keep provider keys server-side.
4. Add platform connections using official OAuth/API flows.
5. Add tests and CI checks.

## Security
Never put AI provider keys, OAuth secrets, or other credentials in browser JavaScript.
